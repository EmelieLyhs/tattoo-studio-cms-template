# 🎨 Modern Tattoo Studio Website & Decap CMS Template

Eine extrem schnelle, mobil-optimierte Jamstack-Website für Tätowierer und Studio-Besitzer. Das Projekt bietet ein integriertes Buchungsformular und ein konfigurierbares Decap CMS Admin-Dashboard zur eigenständigen Inhaltsverwaltung.

---

## ✨ Features

* **Decap CMS Integration:** Dynamisches Admin-Dashboard (`/admin/`) zur einfachen Verwaltung von Galeriebildern, Texten und Preisen.
* **Netlify Identity Ready:** Aufbereitet für Benutzerauthentifizierung und Rollenverwaltung (`admin`) beim Hosting über Netlify.
* **Buchungsformular:** Integrierter Spamschutz (`bot-field`) und Datei-Upload für Referenzbilder.
* **Performance & SEO:** Statisch generierter Code für minimale Ladezeiten und optimale Mobile-Experience.

---

## 🛠 Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **CMS:** [Decap CMS](https://decapcms.org/)
* **Backend Services:** Netlify Forms & Identity (optional bei Deployment)
